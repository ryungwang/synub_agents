# 운영자 작업 체크리스트

운영자 확인 작업은 운영체제별로 분리해서 관리한다. 실행 명령, 설치 파일, 경로, 로그 위치가 다르므로 현재 작업 중인 운영체제 문서를 기준으로 진행한다.

## 체크리스트 문서

- [맥용 운영자 체크리스트](OWNER_ACTION_CHECKLIST_MAC.md)
- [윈도우용 운영자 체크리스트](OWNER_ACTION_CHECKLIST_WINDOWS.md)

## 현재 권장 진행 순서

1. 현재 사용하는 운영체제 체크리스트를 연다.
2. 로컬 대시보드 실행 상태를 확인한다.
3. GitHub 연결 상태를 확인한다.
4. 직원용 앱 오류 제보 흐름을 테스트한다.
5. 직원 ID 생성과 라이선스 부여 흐름을 확인한다.
6. `codex-ready` 라벨 동기화와 작업 큐 전환을 확인한다.
7. 워커 실행과 PR 생성 또는 실패 로그를 확인한다.
8. 직원 PC 설치 테스트와 배포 방식을 결정한다.

## 공통 운영 기준

- GitHub 토큰은 채팅, GitHub Issue, README, 커밋, 로그에 붙여 넣지 않는다.
- 에이전트가 만든 PR은 자동 병합하지 않는다.
- 운영자가 diff, 테스트 결과, 민감 정보 포함 여부를 확인한 뒤 병합한다.
- 직원용 앱은 관리자가 등록하고 라이선스를 부여한 직원 ID로만 사용할 수 있게 운영한다.
- 라이선스를 회수한 직원은 새 인증 또는 재실행 시 앱 사용과 작업 요청이 차단되어야 한다.
- 정보가 부족하거나 테스트성 문구가 포함된 이슈는 `codex-ready` 부여, 동기화, 작업 실행 대상에서 제외한다.
- 운영 방식이 바뀌면 맥용/윈도우용 문서를 함께 갱신한다.
